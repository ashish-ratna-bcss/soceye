# Holehe Web Interface

This is a web interface for the Holehe email checking tool.

## Installation

1. Install the dependencies:
   ```
   pip install -r requirements.txt
   ```

2. Run the web app:
   ```
   python app.py
   ```

3. Open your browser and go to `http://127.0.0.1:5000/`

## Usage

Enter an email address in the form and click "Check" to see if the email is registered on various websites.

## Features

- Simple web interface
- Displays results in cards
- Shows additional info like email recovery, phone numbers, etc.
- Responsive design with Bootstrap
